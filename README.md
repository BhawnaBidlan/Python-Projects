**Python Mini Projects**

This repository contains three simple Python projects: a Countdown Timer, a Dice Game, and a Rock-Paper-Scissors game. Each project is implemented using basic Python concepts such as loops, conditionals, and functions.

**Project 1: Countdown Timer**

Description
The Countdown Timer allows users to set a timer for a specified number of seconds. Once the timer starts, it will count down and display the remaining time in minutes and seconds. When the timer reaches zero, it will notify the user that the time is up.

Usage:
1. Run the countdown.py script.
2. Enter the number of seconds for the countdown when prompted.
3. The timer will display the remaining time in the format mm:ss.
4. When the countdown reaches zero, the message "Time is up!!" will be displayed.

**Project 2: Dice Game**

Description
The Dice Game simulates a dice-rolling competition between the player and the computer. Each player rolls a die, and the one with the higher number wins the round. The game continues until the player decides to exit.

Usage:
1. Run the dice_game.py script.
2. Both the player and the computer will roll a virtual die.
3. The result of each roll will be displayed, along with the current score.
4. Enter "Exit" to stop the game and see the final scores.

**Project 3: Rock-Paper-Scissors Game**

Description
This Rock-Paper-Scissors game pits the player against the computer in a classic game. The player selects one of the three options, and the computer randomly selects one as well. The game determines the winner based on the rules of Rock-Paper-Scissors.

Usage:
1. Run the rock_paper_scissors.py script.
2. Input your choice: "Rock", "Paper", or "Scissors".
3. The computer will randomly select one of the three options.
4. The result will be displayed, and the game will continue until you type "exit".
